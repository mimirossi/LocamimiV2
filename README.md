# LocamimiV2

Landing page di **locamimi** (dj house / hardgroove con latin vibes). HTML + CSS + JS vanilla, nessuna build.

- `index.html` · struttura
- `css/tokens.css` · variabili del Design System (nomi = code syntax Figma)
- `css/style.css` · stili
- `js/sets.js` · **contenuti dei set e link** (SoundCloud, Instagram): si modifica solo qui
- `js/main.js` · carosello fish-eye, card orizzontali, zoom allo scroll
- `assets/` · svg, font DAMN

Anteprima locale: `python3 -m http.server` dalla radice del repo.
